# История изменений Jira Tasklet

Здесь описаны изменения для пользователей. Опубликованные версии и файлы доступны в [GitHub Releases](https://github.com/estkler/jira-task-manager/releases).

## Не выпущено

Пользовательских изменений после 0.9.38 пока нет.

## [0.9.38](https://github.com/estkler/jira-task-manager/releases/tag/v0.9.38) — 2026-11-17

### Исправлено

- При первом открытии окна загрузка задач начинается сразу, без прежней случайной паузы до примерно 40 секунд.
- До первого ответа Jira не показываются ложная ошибка и нулевые счётчики задач. Вместо пустого списка отображается анимация «Загружаем задачи из Jira…».
- При настоящей ошибке загрузки отображаются причина и кнопка «Повторить». Повторное открытие окна не создаёт параллельных запросов.
- Обычный Enter в локальной заметке переносит строку. Отправка комментариев Jira по Ctrl+Enter сохранена.
- Клик мышью по ссылке на задачу в заметке больше не оставляет пунктирную рамку. Фокус при работе с клавиатуры сохранён.
- В подсказках часов отсчёт обновляется во время наведения.

### Изменено

- Бар рабочего дня соответствует ширине текстового таймера, показывает проценты и использует мягкую заливку в обеих темах. Цифры рисуются одним цветом и не разрезаются границей заполнения.
- Подсказка режима бара показывает проценты рабочего дня. Девять часов соответствуют 100%; фактический отсчёт продолжается дальше.

### Файлы для распространения

- Добавлен переносимый ZIP с готовым EXE и инструкцией для коллеги.
- README архива разделён на «Быстрый старт», «Важно» и «Техническая информация». Описаны закрытие в трей, обновления и настройка автозапуска.
- Автопроверка и уведомления о новых версиях уже встроены с 0.9.33.

Промежуточные сборки 0.9.35–0.9.37 использовались локально; их изменения включены в этот публичный релиз.

## [0.9.34](https://github.com/estkler/jira-task-manager/releases/tag/v0.9.34) — 2026-11-12

- Бар рабочего дня стал компактным: его ширина соответствовала цифровому таймеру с учётом шрифта и масштаба Windows.
- Сохранена стабильная позиция подписи «Обновлено» при смене режима таймера.

## [0.9.33](https://github.com/estkler/jira-task-manager/releases/tag/v0.9.33) — 2026-11-09

- Добавлен третий режим таймера рабочего дня — бар. Режимы переключаются правой кнопкой мыши.
- Добавлены автоматическая проверка обновлений после запуска и раз в сутки, а также одно уведомление Windows о новой версии.
- Скачивание и установка остаются действиями пользователя через кнопку «Обновить».
- Исправлены индикаторы сроков для некорректной последовательности дат в Jira.

## [0.9.32](https://github.com/estkler/jira-task-manager/releases/tag/v0.9.32) — 2026-11-09

- Приложение переименовано в Jira Tasklet; обновлены настройки и оформление.
- Добавлены приглушение задач, необязательные вкладки «Все» и «Готово», сроки задач и копирование названия/ссылки.
- Обновление Jira использует постраничный список изменений и получает подробности только новых или изменённых задач. Запросы выполняются последовательно.
- Добавлен зашифрованный локальный кэш для уменьшения повторной загрузки после перезапуска.
- Автообновление данных по умолчанию приостанавливается при блокировке и сне компьютера.

Более ранние изменения сохранены в [предыдущих релизах](https://github.com/estkler/jira-task-manager/releases).
