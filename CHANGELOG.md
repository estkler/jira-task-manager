# История изменений Jira Tasklet

Здесь описаны изменения для пользователей. Опубликованные версии и файлы доступны в [GitHub Releases](https://github.com/estkler/jira-task-manager/releases).

## Не выпущено

Пока нет новых изменений.

## [0.9.48](https://github.com/estkler/jira-task-manager/releases/tag/v0.9.48) — 2026-11-25

- В общих настройках появился виджет рабочего стола. При сворачивании или закрытии в трей он показывает активную задачу и таймер рабочего дня. По умолчанию виджет выключен.
- Виджет стал компактнее, плавно появляется и запоминает положение после перетаскивания. ПКМ по таймеру переключает цифры, слова и проценты. Из меню таймера можно изменить начало дня или открыть анализ рабочего времени.
- Диагностика обновления записывает шаг сбоя и код ошибки Windows, если он доступен. Установщик повторяет проверку при временной блокировке EXE. После сбоя подготовки можно повторить установку с уже скачанным файлом.

Промежуточные версии 0.9.46 и 0.9.47 использовались локально. Их изменения включены в этот релиз.

Если встроенное обновление из старой версии останавливается на подготовке перезапуска, полностью выйдите из Tasklet через меню значка в трее и замените EXE файлом из архива, сохранив имя и папку. Заметки, настройки и таймер хранятся в профиле Windows.

## [0.9.45](https://github.com/estkler/jira-task-manager/releases/tag/v0.9.45) — 2026-11-24

- Кнопки окна обновления сохраняют своё положение и нейтральное оформление. Во время скачивания «Скачать» остаётся видимой и временно недоступна, пока работает «Отмена».
- Окно приложения открывается одним левым кликом по значку в трее. Правый клик продолжает открывать меню.
- При завершении задачи выбранные звёзды остаются видны во время отправки. Блокировка повторного нажатия и сохранение оценки при ошибке не изменились.
- Инструкция в архиве поясняет, когда появляется окно с прогрессом при переходе со старой версии.

Промежуточные версии 0.9.43 и 0.9.44 использовались локально. Их исправления включены в этот релиз.

## [0.9.42](https://github.com/estkler/jira-task-manager/releases/tag/v0.9.42) — 2026-11-23

- Перед скачиванием обновления можно прочитать «Что нового». Описание берётся из того же ответа GitHub, без дополнительного запроса.
- Скачивание обновления показывает прогресс и проценты по фактически полученным данным; проверка файла отображается отдельным этапом. Загрузку можно отменить.
- Карточка смены статуса оформлена в стиле заметок: компактная шапка, мягкая рамка и крестик. Лишняя кнопка подтверждения убрана.
- Двойной клик в области отметки смены статуса не запускает действие над задачей после прочтения изменения.
- Непросмотренные изменения статуса отмечаются небольшой точкой. По нажатию виден прежний и новый статус; открытие карточки убирает отметку. Отметки сохраняются локально после перезапуска.
- После собственного подтверждённого изменения статуса, включая Done, предыдущая отметка снимается автоматически. Дополнительных запросов к Jira для отметок нет.
- Подпись интервала обновления объясняет частоту проверок и значение по умолчанию без неподтверждённых рекомендаций о нагрузке.
- Область срока, включая пустую ячейку, реагирует на клик и двойной клик так же, как остальная строка задачи. Переключение даты и бара через ПКМ сохранено.
- При наведении на название задачи появляется курсор-рука.
- При переключении задачи в In Progress подъём строки и жёлтая заливка происходят одновременно, без сброса цвета и повторного запуска анимации.
- Предыдущая активная задача теряет жёлтый акцент и показывает ожидание синхронизации, пока Jira подтверждает её автоматическую паузу. Статус обновляется только по ответу Jira; дополнительные переходы не отправляются.

Промежуточные сборки 0.9.39–0.9.41 использовались локально; их изменения включены в этот релиз.

В архиве обновлена инструкция: добавлены описание списка изменений, прогресса скачивания и пояснение перехода со старой версии.

При обновлении с 0.9.38 первое скачивание проходит через прежний экран. Новый список изменений и прогресс будут доступны после установки 0.9.42 для последующих обновлений.

## [0.9.38](https://github.com/estkler/jira-task-manager/releases/tag/v0.9.38) — 2026-11-17

### Исправлено

- При первом открытии окна загрузка задач начинается сразу, без прежней случайной паузы до примерно 40 секунд.
- До первого ответа Jira не показываются ложная ошибка и нулевые счётчики задач. Вместо пустого списка отображается анимация «Загружаем задачи из Jira…».
- При настоящей ошибке загрузки отображаются причина и кнопка «Повторить». Повторное открытие окна не создаёт параллельных запросов.
- Обычный Enter в локальной заметке переносит строку. Отправка комментариев Jira по Ctrl+Enter сохранена.
- Клик мышью по ссылке на задачу в заметке больше не оставляет пунктирную рамку. Фокус при работе с клавиатуры сохранён.
- В подсказках часов отсчёт обновляется во время наведения.

### Изменено

- Бар рабочего дня соответствует ширине текстового таймера, показывает проценты и использует мягкую заливку в обеих темах. Цифры рисуются одним цветом и не разрезаются границей заполнения.
- Подсказка режима бара показывает проценты рабочего дня. Девять часов соответствуют 100%; фактический отсчёт продолжается дальше.

### Файлы для распространения

- Добавлен переносимый ZIP с готовым EXE и инструкцией для коллеги.
- README архива разделён на «Быстрый старт», «Важно» и «Техническая информация». Описаны закрытие в трей, обновления и настройка автозапуска.
- Автопроверка и уведомления о новых версиях уже встроены с 0.9.33.

Промежуточные сборки 0.9.35–0.9.37 использовались локально; их изменения включены в этот публичный релиз.

## [0.9.34](https://github.com/estkler/jira-task-manager/releases/tag/v0.9.34) — 2026-11-12

- Бар рабочего дня стал компактным: его ширина соответствовала цифровому таймеру с учётом шрифта и масштаба Windows.
- Сохранена стабильная позиция подписи «Обновлено» при смене режима таймера.

## [0.9.33](https://github.com/estkler/jira-task-manager/releases/tag/v0.9.33) — 2026-11-09

- Добавлен третий режим таймера рабочего дня — бар. Режимы переключаются правой кнопкой мыши.
- Добавлены автоматическая проверка обновлений после запуска и раз в сутки, а также одно уведомление Windows о новой версии.
- Скачивание и установка остаются действиями пользователя через кнопку «Обновить».
- Исправлены индикаторы сроков для некорректной последовательности дат в Jira.

## [0.9.32](https://github.com/estkler/jira-task-manager/releases/tag/v0.9.32) — 2026-11-09

- Приложение переименовано в Jira Tasklet; обновлены настройки и оформление.
- Добавлены приглушение задач, необязательные вкладки «Все» и «Готово», сроки задач и копирование названия/ссылки.
- Обновление Jira использует постраничный список изменений и получает подробности только новых или изменённых задач. Запросы выполняются последовательно.
- Добавлен зашифрованный локальный кэш для уменьшения повторной загрузки после перезапуска.
- Автообновление данных по умолчанию приостанавливается при блокировке и сне компьютера.

Более ранние изменения сохранены в [предыдущих релизах](https://github.com/estkler/jira-task-manager/releases).
